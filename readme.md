# Book Store

Eine Buchübersicht mit HTML, CSS und JavaScript, in der Bücher als Karten dargestellt und mit Likes und Kommentaren versehen werden.

## Starten

Das Repository herunterladen oder klonen und `index.html` in einem aktuellen Browser öffnen. Alternativ über einen lokalen Webserver bereitstellen. Es gibt keinen Installations- oder Build-Schritt und keine Paketabhängigkeiten.

## Funktionen und aktueller Stand

- Buchkarten mit den im Projekt hinterlegten Buchdaten.
- Likes setzen oder entfernen und favorisierte Bücher anzeigen.
- Kommentare zu Büchern hinzufügen.
- Die Anwendung speichert die Buchdaten im LocalStorage des Browsers. Es gibt keinen serverseitigen Datenspeicher.

## Projektstruktur

- `index.html`: Startseite der Buchübersicht
- `script.js`: Darstellung, Likes, Kommentare und LocalStorage
- `scripts/db.js`: Ausgangsdaten der Bücher
- `scripts/template.js`: HTML-Vorlagen
- `style.css`: Hauptgestaltung
- `styles/`: Weitere CSS-Dateien
- `assets/`: Bilder und weitere Ressourcen
